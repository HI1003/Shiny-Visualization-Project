# 2026-11-04：概率显示与计算精度

用户在实际体验中指出小数位数过多。本轮对照本地 STATS125 2026 手册，统一交互概率表、编辑框、条件概率、期望公式和 Overview 图形/数值读数的显示方式。

## 呈现规则与课程依据

手册 p97 使用短小数；p114、119 保留分数；p113 提示比较时可统一分数/小数；p148 同时提供精确形式与小数读数。上述页面已在本地渲染检查，源 PDF 指纹与课程索引一致。四位小数及简洁分数的分母上限是本项目的界面选择，不声称是课程统一规则。PDF、页面图像和文本均留在 G 盘或忽略的 `.local/`。

- 侧栏 **Probability table display**：Auto / Short decimals / Simple fractions，由 Joint、Conditional、Expectation 共享；更改样式不改变输入草稿、提交概率或练习完成数。
- Auto 优先短小数；可在数值精度内恢复的简洁分数显示为分数。Simple fractions 仅在分母不超过 500、误差在机器精度范围内时使用，其他值回退为短小数；不会把任意截短小数当作精确分数。
- 普通近似小数最多四位、去末尾零；真正的 0、1 保持整数。不能在这个精度下非零显示的数值改用科学计数法，包括 `0.00005` 这样的半舍入边界。近似单元格及相应公式步骤标注 `≈`。
- 表格、编辑框和期望结果悬停可查看完整数值；Plotly 悬停补充六位读数。Overview 默认四位读数，另可展开 **More precision** 查看完整计算值。坐标、密度和概率仍分别标注，未把密度改称为概率。
- 原题的静态题干、表格、参考答案及私有题库不重写；交互表格/图形的显示可以切换。独立游戏和持久化成绩不在本轮范围内。

## 防止显示值覆盖真实值

原先 `pmf_prepare()` 用可往返解析的字符串保留数值精度，但这些字符串直接显示到编辑框和表格，可能出现很长的小数。

现在 `p_input`、`p_value` 仍保留原有精度；编辑器另外生成紧凑文本。读取浏览器输入时，如果内容仍与该条目的原显示文本一致，则保留原始值；真正修改后才解析新输入。表格呈现使用完整值，显示模式只影响文本；归一化和生成操作继续采用原校验、共享状态和新 ID 规则。不能用四舍五入后的小数替换底层数据来“解决”长小数。

这也覆盖切换模块、切换显示模式、重复 Generate、Normalize 后立即 Generate、清空/负数输入等情况。近似编辑框标注 `p (approx.)`，说明文字告知未经编辑的条目保留原精度。
